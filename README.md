# Drake — Views

A fan website for Drake's 2016 album *Views*, built with HTML, CSS, and JavaScript.

## Features

- Responsive layout with mobile hamburger menu
- Album promo, top tracks with Spotify embeds, tour section, and social links
- Sticky navbar with in-page navigation

## Usage

Open `index.html` in any modern browser. No build tools required.
